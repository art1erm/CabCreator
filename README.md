# CabCreator

Веб-приложение для проектирования корпусного шкафа из ЛДСП по размерам.

**Версия 0.1**

## Возможности

- Габариты корпуса: ширина, высота, глубина, цоколь.
- Секции: ширина вручную или «авто», наполнение (полки или штанга с антресолью), 0–2 двери.
- 2D вид спереди с размерными линиями, показ дверей с направлением открывания.
- Разрез выбранной секции (вид сбоку): глубина, полки с отступом от фасада, ХДФ, штанга, дверь, цепочка размеров просветов.
- Просветы между полками: вводятся для каждой секции снизу вверх или задаются перетаскиванием полки на чертеже; пустые поля делят остаток поровну.
- Спецификация деталей: готовые размеры, кромка по торцам (Д1/Д2/Ш1/Ш2), размеры распила с вычетом кромки ≥1 мм.
- Карты раскроя листов ЛДСП (гильотинный раскрой) с учётом пропила, обзола и направления текстуры.
- Расчёт фурнитуры и расходников: кромка, конфирматы, полкодержатели, петли, штанга, опоры.
- Выгрузка: PDF чертежей (общий вид, спецификация, фурнитура, карты раскроя), CSV деталей, SVG раскроя, проект в JSON.

## Запуск

Откройте `index.html` в браузере — сборка и интернет не нужны (без сети шрифты заменятся системными).

Все выгрузки работают офлайн: PDF собирается встроенным генератором без внешних библиотек, файлы скачиваются обычной загрузкой браузера. Внутри Claude используется сохранение через окно подтверждения. Кнопка «Скачать приложение» сохраняет всё приложение одним HTML-файлом.
