# CabCreator

Веб-приложение для проектирования корпусного шкафа из ЛДСП по размерам.

**Версия 0.2**

## Возможности

- Габариты корпуса: ширина, высота, глубина, цоколь.
- Секции: ширина вручную или «авто», наполнение (полки или штанга с антресолью).
- Двери по выбору: каждая дверь закрывает диапазон от низа/полки до полки/верха, 1 или 2 створки; часть полок можно оставить открытой, над и под открытой зоной — отдельные двери. Если дверь граничит с открытой полкой, полка становится неподвижной на всю глубину (как дно и крышка), а дверь накладывается на неё вровень; между двумя дверями стык по центру полки.
- 2D вид спереди с размерными линиями, показ дверей с направлением открывания.
- Вид сбоку справа от вида спереди, в двух режимах: «Вид слева» (снаружи, скрытые кромки пунктиром) и «Разрез секции»: глубина, полки с отступом от фасада, ХДФ, штанга, дверь, цепочка размеров просветов.
- Просветы между полками: вводятся для каждой секции снизу вверх или задаются перетаскиванием полки на чертеже; пустые поля делят остаток поровну.
- Спецификация деталей: готовые размеры, кромка по торцам (Д1/Д2/Ш1/Ш2), размеры распила с вычетом кромки ≥1 мм. Кромку на каждой стороне можно задать самому: нажатие на сторону детали в спецификации переключает нет → 0,4 → 1 → 2 мм для всех деталей с этим названием.
- Карты раскроя листов ЛДСП (гильотинный раскрой) с учётом пропила, обзола и направления текстуры.
- Расчёт фурнитуры и расходников: кромка, конфирматы, полкодержатели, петли, штанга, опоры.
- Присадка: для каждой детали (боковины, перегородки, крышка, дно, цоколь, неподвижные полки, двери) рассчитываются отверстия под конфирматы 7×50, полкодержатели, чашки петель Ø35 и ответные планки (ряд 37 мм), штангодержатели. Отверстия под ручки не размечаются: ручки подбираются индивидуально и сверлятся по месту.
- Выгрузка: PDF чертежей (общий вид, разрезы, спецификация, фурнитура, карты раскроя, листы присадки с таблицей координат отверстий, инструкция по сборке без слов в изометрии: обложка, правила безопасности, комплектация с номерами деталей и кодами крепежа, шаги со стрелками и количеством крепежа), CSV деталей, проект в JSON. Кнопки выгрузки — внизу страницы.

## Запуск

Откройте `index.html` в браузере — сборка и интернет не нужны (без сети шрифты заменятся системными).

Все выгрузки работают офлайн: PDF собирается встроенным генератором без внешних библиотек, файлы скачиваются обычной загрузкой браузера. Внутри Claude используется сохранение через окно подтверждения.

## Что нового в 0.2

- Вид сбоку рядом с видом спереди: снаружи и в разрезе секции; горизонтальная прокрутка чертежа на узких экранах.
- Просветы между полками: ввод по секциям и перетаскивание полок на чертеже.
- Двери по выбору: несколько дверей в секции, открытые зоны, стык вровень с неподвижной полкой.
- PDF: разрезы, листы присадки с таблицами координат, инструкция по сборке в картинках.
- Подпятники вместо регулируемых опор; ручки подбираются по месту, без присадки.
- Выгрузка без Claude и без интернета: встроенный генератор PDF и обычное скачивание файлов.
- Обратная связь: сообщения об ошибках и предложения приходят в Telegram-бота.

## Обратная связь

Кнопка «Сообщить об ошибке» открывает форму: ошибка или предложение, текст, контакт и, по желанию, текущий проект. Сообщение уходит в Telegram-бота через посредника на Cloudflare Workers — токен бота в код страницы не попадает. Настройка описана в [worker/README.md](worker/README.md); после неё впишите адрес посредника и username бота в `FEEDBACK` в `index.html`.
